# Engineering decisions for the proxy rewrite

The revised audit inspected commit `24e5b0e`. Its source findings and estimates have different implications for the shipping app. The standalone imported-photo editor has a separate development repository.

| Area | Decision and evidence required |
| --- | --- |
| Routing and TLS | Keep the explicit loopback proxy and upstream certificate verification. PAC, CONNECT and HTTPS interception must agree on exact host scope. All-sites mode bypasses local suffixes and rejects malformed labels. For included destinations the loaded PAC now specifies only the proxy. PAC acquisition failures and browser-local pixels remain separate coverage limits. A transparent provider would require deployment approval and separate compatibility tests. |
| HTTP coverage | Current main already checks raster signatures, handles bounded gzip and deflate, preserves empty responses and scans no-transform images. Unknown lengths still require an engine-level collector that can withhold headers and every original byte through the verdict. Switching on streaming alone cannot satisfy that contract. |
| Load and isolation | Reserve declared body capacity before buffering. Limit pending images to 48 and their combined declared size to 48 MiB. A full queue withholds new candidates. This budget excludes decompressed bodies, model memory, result cache and captures. Queue wait plus model service has a 20-second deadline after decoding the HTTP content encoding. |
| Worker and caching | Snapshot appearance per scan. Frame settings separately from the image. Keep the model process resident across slider changes and reuse clear results across appearance settings. Positive renders are keyed by content and appearance. An optional disk cache needs a demonstrated benefit and expiry policy. |
| Recognition | Keep the existing models as controls. Compare person segmentation, person-instance segmentation and a compact specialist on the same held-out scenes. Include distant figures, overlapping people, thumbnails at 255/256/257 pixels and object-only negatives. A face box proves little about coverage of a whole body. Generic foreground selection can cover merchandise. |
| Rendering | Keep original clear bytes and lossless masked output as regression controls. Compare per-person boxes, opaque cores, margin and cheaper blur on images with transparent edges and rotated orientation. A lossy codec needs an explicit background fidelity tolerance. |
| Hardware and latency | Benchmark cold and warm runs, bursts of 1/8/32 images, cache hit ratio, queue latency, memory and energy on the M4 with 16 GB. Compare worker counts before increasing concurrency. Published inference estimates and accelerator eligibility are insufficient to claim a speedup. |
| Lifecycle and distribution | Test setup cancellation, crash recovery, sleep/wake, competing proxies and restoration on disposable macOS services. Ad-hoc signatures and a checksum do not establish a pinned publisher identity. Release authentication, health-checked rollback and protected CA storage still need work. |
| Other media and diagnostics | A proxy can cover fresh CSS image requests. Browser-local pixels need browser cooperation. Sampling a few animation frames cannot establish that every frame is clear. Preserve opt-in diagnostic capture and inspect exports for unmasked originals before sharing. |
| Editor and macOS 27 experiments | Interactive foreground refinement fits a manual photo editor. SAM, multimodal rescue, Core AI, stage-specific compute overrides and persistent caches need feature availability, licensing and measured gains before adoption. |

## Measure a labeled collection

Put still images in two local folders, `corpus/people/` and `corpus/clear/`. From this checkout, run `python3 tests/benchmark_worker.py corpus results.csv` on the Mac with the app installed. The command uses the bundled worker, processes the collection twice, and writes one row per observation. The second pass measures warm model execution without the proxy cache. It includes worker IPC and rendering for positive images. It excludes network transfer, proxy queueing, and application startup. A correct image-level verdict can still leave a second person uncovered, so inspect masks separately for coverage.
